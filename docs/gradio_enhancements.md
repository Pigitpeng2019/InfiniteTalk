## 1. 任务队列系统

### 功能说明
支持同时添加多个生成任务，任务按顺序依次执行。适合批量生成场景。

### 使用方法
1. 在 **"生成"** 标签页设置好参数
2. 点击 **"添加到队列"** 按钮（绿色主按钮）
3. 可在 **"任务队列"** 标签页查看所有任务状态
4. 任务完成后，结果自动显示在右侧视频区域

### 任务队列标签页
- **刷新** — 手动刷新任务列表
- **清除已完成** — 移除已完成和失败的任务记录

### 两种生成方式
| 方式 | 按钮 | 特点 |
|------|------|------|
| 添加到队列 | "添加到队列" | 不阻塞界面，可连续添加多个任务 |
| 立即生成 | "立即生成" | 同步执行，带 Gradio 进度条，适合单次快速测试 |

## 2. 实时进度显示

### 进度阶段
```
准备音频... → 提取音频特征... → 生成视频中... → 保存视频...
```

### 使用方式
- **队列模式**：在"任务队列"标签页查看百分比进度和阶段文字
- **立即生成模式**：顶部显示 Gradio 原生进度条 + 阶段描述文字

### 自动刷新
- 结果视频区域每 5 秒自动检查最新完成的任务
- 任务队列需要手动刷新（页面自动聚焦在最新任务）

## 3. 历史记录管理

### 存储位置
- 历史数据：`history/history.json`
- 历史视频：`history/videos/` 目录

### 功能
- 每次生成完成后自动保存到历史记录
- 显示最近的 50 条记录
- 支持按索引查看历史视频
- 支持删除单条记录（同时删除对应的视频文件）
- 最大保留 200 条记录，超出时自动清理最旧的

### 使用方法
1. 切换到 **"历史记录"** 标签页
2. 点击 **"刷新"** 查看最新历史
3. 在 # 输入框中输入序号（0 表示最新）
4. 点击 **"查看"** 播放历史视频
5. 点击 **"删除"** 删除选中的历史记录

## 4. 中英文界面切换

### 功能
支持中文和英文两种界面语言，覆盖所有 UI 标签、按钮、提示文字。

### 使用方法
1. 在页面顶部的语言切换栏中，选择 **"中文"** 或 **"English"**
2. 语言偏好会自动保存（存储在 `.lang_pref.json`）
3. 下次打开页面时会自动沿用上次的语言设置

### 覆盖范围
- 所有标签页名称
- 所有按钮文字
- 表单标签和占位符
- 进度阶段描述
- 状态提示和错误信息

## 5. 参数预设管理

### 存储位置
- `presets/` 目录，每个预设保存为一个 JSON 文件

### 功能
- 保存当前常用参数配置为预设
- 加载已保存的预设快速填充参数
- 删除不需要的预设

### 当前可保存的参数
- 扩散步数（Diffusion Steps）
- 随机种子（Seed）
- 文本引导系数（Text Guide Scale）
- 音频引导系数（Audio Guide Scale）

### 使用方法
**保存预设：**
1. 切换到 **"参数预设"** 标签页
2. 在左侧"预设名称"输入框中输入名称
3. 点击 **"保存预设"**

**加载预设：**
1. 在右侧下拉框中选择一个预设
2. 点击 **"加载预设"**，参数自动填充到生成面板

**删除预设：**
1. 在下拉框中选择要删除的预设
2. 点击 **"删除"**

## 6. 错误处理

### 改进内容
- 生成异常时自动捕获错误，记录错误信息和调用栈
- 在任务队列面板中显示失败状态
- 失败任务的详细错误信息记录在日志中
- 即使在生成过程中出错，也会尝试保存已生成的片段

### 常见错误
| 错误 | 可能原因 | 解决 |
|------|---------|------|
| 缺少音频文件 | 未上传条件音频 | 确保上传了音频文件 |
| 缺少输入图片 | 未上传参考图片/视频 | 确保上传了输入 |
| CUDA OOM | GPU 显存不足 | 降低分辨率或减少参数 |

## 7. 技术说明

### 依赖
- Python 标准库（`threading`, `queue`, `json`, `shutil`, `copy`）
- 无外部数据库依赖

### 数据存储
```
workspace/
├── app.py              # 主程序
├── history/
│   ├── history.json    # 历史记录（JSON 格式）
│   └── videos/         # 历史视频文件
├── presets/            # 参数预设（JSON 格式）
└── .lang_pref.json     # 语言偏好
```

### 任务队列架构
- 使用 `threading` + `queue.Queue` 实现
- 后台 Daemon 线程逐任务处理
- 线程安全（使用 `threading.Lock`）
- 任务状态：排队中 → 运行中 → 已完成 / 失败

### 兼容性
- 完全兼容原有的所有功能（SingleImageDriven / VideoDubbing）
- 所有原有参数和操作方式保持不变
- 不会修改核心模型代码
